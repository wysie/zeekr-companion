# Factory 360 camera research

This branch investigates reuse of the ZEEKR 009’s factory stitched bird’s-eye
camera view. It contains research notes and a read-only ADB collection tool;
no factory feed has been identified or implemented yet.

- [Research findings and collection steps](docs/factory-360-view-research.md)
- [Read-only collection tool](tools/collect_factory_360.py)
- [Current combined app and credits on main](https://github.com/wysie/zeekr-shortcut-car/blob/main/README.md)
- [Download the fork's APKs](https://github.com/wysie/zeekr-shortcut-car/releases)

Build the installable app from **main**. This research branch is not an APK release.
