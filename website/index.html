    Use Back at the top left of the installer, rather than Open. Then launch Companion and check the camera sources while parked.

    Make your first recording.

Questions or feedback? GitHub issues ↗
Is this an official ZEEKR app?+

No. Zeekr Companion is an independent project maintained by wysie. It is not affiliated with, approved by or endorsed by ZEEKR.

Will it work on my model?+

This fork is primarily developed for the owner's ZEEKR 009. Camera access and behavior depend on the head unit and firmware. Compatibility with other models is not established. Review the documentation before installing.

What triggers the blind spot camera?+

The side camera responds to turn signals. The main-screen view uses your configured speed threshold; HUD output has no app speed threshold. Camera access still yields to factory ownership. It does not detect obstacles or replace the factory blind-spot warning system.

Can I update an existing installation?+

Companion retains the existing Android package ID and signing identity for compatible in-place updates. Export a settings backup before testing. Alpha updates require selecting the Alpha channel under Updates.

Why is the download an alpha?+

This is an actively developed personal fork. Automated checks and builds are part of development, but vehicle testing is limited. Read the release notes for the current changes and known limitations.
