Release notes · 3.0.0-alpha.2

  1. Download and sideload

    Get the APK from Releases and install through App Lab. When it finishes, press Back, then launch Companion separately. The installer’s Open button can leave it stuck.

  2. Choose cameras and storage

    While parked, check Recording & photos in Settings and choose a USB drive under Storage. Tap Apply changes if shown.

  3. Try a short recording

    Record manually, then check Videos. Automatic recording starts off. For alpha updates, choose Updates → Update channel → Alpha.

Before using it

This personal fork is experimental, with limited vehicle testing. Factory cameras take priority. Side views follow the turn signal, not obstacle detection; DIY 360° alignment is approximate. Configure while parked and keep using the factory safety systems.
